# Evidence directory

This directory contains local prototype measurements. It is separate from the fictional examples and targets on the concept landing page.

| Artifact | Meaning |
|---|---|
| `verification-latest.json`, `verifications/` | Syntax/contracts and complete local automated suites, code fingerprints, hardware and counts |
| `provider-smoke.json` | Configured provider/model availability and real response receipt |
| `media-byte-smoke.json` | Processing actual permitted synthetic bytes; not independent accuracy measurement |
| `runs/service-live-*.json` | Real provider investigation, independent scoped owners, modeled physical execution and occupied service; successes and failures retained |
| `runs/live-response-*.json` | Actual ×1 source/model/order/travel/receipt episodes, including late, partial and failed outcomes |
| `evaluations/<id>/protocol.json` | Before-run scenario/seed/model/code/clock/budget/arm declaration |
| `evaluations/<id>/S*-B*.json` | Per-episode outcome, model calls, actual charged/unknown cost, errors and physical metrics |
| `evaluations/<id>/summary.json` | Complete or incomplete campaign; missing outcomes remain explicit |
| `evaluations/<id>/contrasts.json` | Same-model and conventional-sharing contrasts, losses included, service units kept separate |
| `load-latest.json`, `load/` | HTTP ingestion and durable version storage under load; not semantic throughput |
| `ui-*.json` | Automated viewport, keyboard, mobile, offline and review workflows; not human comprehension |
| `real-source.json` | Real read-only external source access; not an institutional agreement |

Read `docs/VALIDACION.md` and `docs/ESTADO_IMPLEMENTACION.md` before citing a result. Inspect its fingerprint and scope: model/prompt/code changes do not inherit previous measurements. Never treat a workflow acknowledgement as semantic accuracy, an arriving truck as received aid, an empty shelter as occupied service, or a simulated health curve as real lives saved.

Provider IDs and local fictional identifiers are included for provenance. API keys, actor keys, login credentials, private working databases, original media and backup bundles stay in ignored local storage. The repository is private. Do not publish reports containing real sensitive information without a separate review.
