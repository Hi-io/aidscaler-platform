# Local campaign orchestration

These exact files run from the platform checkout's ignored .local directory. Copy the listed files there without changing their bytes; their relative imports require that location. Install dependencies in both sibling repositories, provide a server-only environment key, and first run node .local/full-gates.mjs.

After the complete stable unit and browser gates pass, declare the fresh three hashes with node .local/refresh-measurement-plans.mjs. The current plan files in reports specify every seed, arm and budget. Run stream-plan.mjs free reports/discovery-followup-plan.json primary, retain its returned index, then use that exact index in the paid invocation. Controls use the same sequence with controls as section.

The information-load preflight requires --go and zero provider calls. Write a rationale from its closed funnel before admitting the paid sensitivity; never replace a negative primary with that workload. General-agent-reuse requires the exact newly completed B6 report and checks its bytes/configuration. recovery-series requires --go. Research and geometry require --freeze=reports/measurement-freeze-current.json and their explicit ROOT_GO_K07, ROOT_GO_K14 or ROOT_GO_K18 argument. Only one paid study runs at a time. Stop markers, failed/missing outcomes, costs and old evidence must remain.

The delegated plan contains the exact S19 command; launch only after all three gates match. Archived helpers do not authorize inference automatically. Never run from this archive directory or print local environment credentials. No source edit is permitted during an experiment.
